# 최후의 기지 (THE LAST STATION) — Sci-Fi Tower Defense

Phaser 3 기반 HTML5 타워 디펜스. 별도 빌드 과정 없이 `index.html`을 열면(또는 정적 서버로 서빙하면)
바로 실행됩니다.

## 실행 방법

### 로컬에서 바로 열기
`index.html`을 브라우저로 더블클릭해서 열면 됩니다 (스크립트가 전부 `<script>` 태그 기반이라
모듈 CORS 문제 없이 `file://` 에서도 동작합니다).

### 로컬 서버로 실행 (권장)
```bash
python -m http.server 8000
```
그 다음 브라우저에서 `http://localhost:8000` 접속.

## 배포
`index.html`, `lib/`, `src/` 전체를 그대로 GitHub Pages 또는 itch.io(zip 업로드)에 올리면 됩니다.
외부 리소스(이미지/폰트/사운드 파일)를 전혀 쓰지 않고 전부 코드로 생성하므로 폴더 통째로 복사만
하면 됩니다.

## 콘텐츠

- **타워 6종**: 펄스 캐논(단일) / 플락 모르타르(광역) / 크라이오 이미터(슬로우) /
  레일 스나이퍼(관통) / 톡신 스파이어(도트) / 테슬라 코일(스턴). 각 타워는 레벨 1→3 업그레이드 가능.
- **적 4종 + 미니보스**: 일반(드론) / 빠른(인터셉터) / 탱커(저거너트, 슬로우·스턴 저항) /
  회피(팬텀, 물리 공격 무효화 — 광역/도트/스턴만 유효). 6·12웨이브에 보스(오버로드) 등장.
- **웨이브 12개**: 초반 일반형 → 중반 빠른/탱커 → 후반 회피형 혼합 + 보스.
- **비주얼**: 모든 스프라이트/배경/파티클을 Canvas2D로 코드에서 직접 생성 (외부 이미지 파일 없음).
- **사운드**: Web Audio API로 절차적 합성 (엔벨로프+필터+약한 리버브). 외부 오디오 파일 없음.
- **로깅/데이터 저장 없음**: 이번 빌드는 영상 분석 전용 데모라 의도적으로 넣지 않았습니다.

## 밸런스 조정
`src/data/balance.js` 한 파일에 타워/적/웨이브/업그레이드 수치가 전부 모여 있습니다.

## 디버그 플래그
`index.html?forceRender=1` 로 열면, 브라우저 탭이 "숨김" 상태로 인식되어도(예: 화면 녹화 툴에
따라) Phaser 자체의 절전 일시정지를 무시하고 계속 렌더링합니다. 일반 플레이에는 필요 없습니다.
